# Sarah Valmonte · Reels für Hotels & Restaurants

Einseitige Portfolio-Website (reines HTML, CSS und JavaScript, kein Build-Schritt).

## Struktur

```
index.html          Seite mit Styles und Skripten
media/              Videos, Poster und Bilder
impressum.html      Impressum
```

## Lokal ansehen

```bash
python3 -m http.server 8000
```

Dann http://localhost:8000 öffnen.

## Veröffentlichen mit GitHub Pages

Repository Settings → Pages → Branch `main`, Ordner `/ (root)`.

## Hinweise

- Das Foto im Journal-Eintrag „Zwischen Uni und Gym“ wird von Unsplash geladen.
- Die Videos sind H.264-MP4 und liegen mit rund 5,5 MB zusammen im Repo. Für größere Dateien lohnt sich Git LFS.
